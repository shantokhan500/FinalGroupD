# Project Features

The Student Management System currently supports the following data fields for each student:

- **Student ID (`studentId`)**: Unique identification number for the student.
- **Student Name (`studentName`)**: Full name of the student (up to 100 characters).
- **Age (`age`)**: Current age of the student.
- **CGPA (`cgpa`)**: Current Cumulative Grade Point Average.
- **Department (`department`)**: Enrolled department name.
- **Email (`email`)**: Contact email address.
- **Phone Number (`phone`)**: Contact phone number (up to 25 characters for international formats).
- **Address (`address`)**: Residential address (up to 200 characters).
- **Gender (`gender`)**: Student's gender.
- **Semester (`semester`)**: Current academic semester.
- **Credit Hours (`creditHours`)**: Total completed credit hours.
- **Status (`status`)**: Current enrollment status (e.g., Active, Inactive, Graduated).
